# FEWT Project - Movie Explorer (CineVerse)

Frontend Web Technologies (FEWT) Semester 3 project featuring a modern movie discovery and watchlist application.

## Project Structure

This repository contains the following components:

- **[`react-movie-app/`](./react-movie-app)**: Main React application built with **React 19**, **Vite**, **React Router v7**, and **Axios**. Features real-time TMDB API integration, live trending feeds, search with multi-filter discovery, responsive watchlist management, and dynamic movie detail views with custom placeholder fallbacks.
- **[`static pages/`](./static%20pages)**: Core web version implemented using semantic **HTML5**, modern **CSS3**, and vanilla **JavaScript**.
- **[`fewt project react/`](./fewt%20project%20react)**: React implementation workspace.

## Quick Start (React App)

1. Navigate to the React app folder:
   ```bash
   cd react-movie-app
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
